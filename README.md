# XenO

**XenO** is a modern Minecraft launcher built with **Electron, Node.js, JavaScript, HTML, and CSS**.

Designed for **Windows 11 64-bit**, XenO aims to provide a clean, fast, and secure way to manage Minecraft.

## Current Features

* Modern dark UI
* Home dashboard
* Sidebar navigation
* Versions page
* Mods page
* Accounts page
* Settings page
* PLAY button
* Modular Electron architecture
* Secure preload/IPC setup
* npm development workflow

## Planned

## Development

```bash
npm install
npm start
```

Build XenO:

```bash
npm run build
```

The goal is to produce:

```text
XenO.exe
```
